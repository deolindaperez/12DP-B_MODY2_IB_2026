# 12DP-B_MODY2_IB_2026

Disease Project of Introduction to Bioinformatics (UPC, 2026). Genetic and proteomic characterisation of the glucokinase E339K variant in MODY2.

**Research question:** How can changes in gene/protein sequence and structure explain the molecular basis of disease, and what can comparison tell us about the affected biological function?

**Team (group 12DP-B):** Maeve López Pardo, Deolinda Pérez, Biel Porté, Unai Ros, Ariadna Sospedra.

## Repository structure
- `report/Paper.md`: main project report (BMC Bioinformatics format)
- `status/Status_livedoc.md`: project status document
- `gantt/`: Gantt v1 (delivered 09/10 and corrected) and Gantt v2 (plan vs real) with the retrospective
- `references/`: articles, sequences and source files used in the report
